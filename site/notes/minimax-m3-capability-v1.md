## 3. 关键结论

1. **格式化窄任务可靠**：严格 schema 的 JSON 产物、单行精确编辑、短句批量翻译（≤3 句/批实测）可以下放，机器验收能完整覆盖。
2. **计数/检索类任务必须规定口径**：「出现次数」要写明含闭合标签、按 occurrence 不按行；结论仍需主线程复核。
3. **规格边界向 ASCII 收缩**：涉及 Unicode 的规格必须附边界用例表（é、全角、假名、emoji），由主线程 harness 跑向量验收，不接受 CLI 自测自述。
4. **自报 ≠ 产物（最严重）**：P4 自报与实际输出不符；P5 产物落错路径仍称「已落盘」；P5R 在被指出缺失后于错路径上重写并真实回读，继而自信反指验收方「与文件系统状态不符」，全程未对照任务书指定路径。**凡 M3 的确认、复述、回读、自检声明一律不可信，验收只能以主线程机器检查为准（含正确路径上的存在性检查）。**
5. **多模态读图（初判，已被 §6 修正）**：P5/P5R 中读图答案三项逐字幻觉、一项布尔误判，模型以幻觉兜底且不报错——但该结论受混杂因素污染，**以 §6 分级结论为准：干净背景 OCR 与宏观判断条件可用，纹理底/反白文字禁派**。
6. **与 deepseek-v4-flash[1m] 的实测对比**（deepseek 数据来自同工程生产任务实绩，非探针；M3 数据为本报告 P1–P5R）：

| 维度         | deepseek-v4-flash[1m]                                                                                                             | MiniMax M3                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 任务粒度上限 | 多步骤审计 + 200+ 行断言脚本（verify-dist.mjs 一次成型，仅 2 处正则手滑；修复后直接揪出 main.ts SSG head 回归）                   | 单产物单动作窄任务（严格 schema JSON、单行编辑、≤5 句翻译、≤60 行小函数）                   |
| 自报可信度   | 四会话全部属实（路径/计数/结论与产物一致），零虚报                                                                                | 两次自报与产物不符（'deja' vs 'dj'；「已落盘」但落错路径），一次自信反指验收方且不自查      |
| 不确定性处理 | **主动上报**：fr 长词 3 处自行标注存疑请主线程复核；报告发现按 🟡🟢 分级，无夸大                                                  | 给了「不可读」诚实出口仍虚构内容兜底                                                        |
| 错误模式     | 正则/转义手滑（unicode-range 解析 ×2、注释内 `**/*` 提前闭合）——机器可捕获、修复即过，产物数据文件（sitemap/翻译/manifest）零错误 | 口径默认化（行数≠出现次数）、规格边界向 ASCII 收缩、路径纪律失败、读图幻觉——理解力/可信度级 |
| 翻译质量     | ja/ko/fr 全站 + themePreview 量产，交叉引用 app 本体官方词条，键对称零缺                                                          | 3 句级短翻译质量自然达标（P2），量产能力未验证                                              |
| 结构化产物   | sitemap.xml 21 URL×6 alternate 一次写对并自验计数正确                                                                             | P1 严格 schema 正确（仅漏尾随换行）                                                         |
| 多模态       | 无实测场景                                                                                                                        | 名义支持，实测读图幻觉不可用                                                                |

**定位结论**：M3 当前是 deepseek 能力的下游子集——只能接 deepseek 可完成任务中最窄的切片，且所有验收必须主线程机器化。verify-dist.mjs 级别（多文件上下文 + 长脚本 + 自洽计数）的任务 M3 暂不可派：主线程手写，或 `--model "deepseek-v4-flash[1m]"` 回退 deepseek 会话（注册表仍保留该模型约束段）。

## 4. 任务适配表（M3 可派/禁派）

**可派（机器可验的窄任务）**：格式化 JSON/配置产物；单文件单行级精确编辑；≤5 短句/批的翻译；规定口径的只读统计（结论复核）；附边界向量的小函数。

**禁派**：纹理/图案底与反白文字的读图（§6）；长脚本/多文件架构性改动；任何无法机器验收的产物（ prose 质量、设计判断）；任何依赖其自报的流程节点。

**通用规则**：任务书含「禁改范围 + 停止点 + 最终消息只列产物路径」；验收一律主线程机器化（schema 校验/向量 harness/真值对照/marker 越界扫描）；产物落 `scratch/` 沙箱先行，验收后转正。

## 5. 复跑方式

探针产物与 harness 在 `scratch/m3-probe/`（含各会话最终消息转述见任务日志）；更新模型或 prompt 策略后按 §1 同法复跑，报告版本号 +1。

## 6. 修正复验（V 轮，2026-08-04）：视觉能力分级结论

P5 的结论（多模态读图不可用）受三个混杂因素污染：相对路径纪律失败、全页大图降采样、细字与宏观混问。V 轮逐项排除后复验（产物全部落对绝对路径）：

| 探针 | 条件                  |    结果     | 明细                                                                                                                                                                                        |
| :--: | --------------------- | :---------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  V1  | 全页大图，只问宏观    |   ✅ 全对   | bandCount=4 ✓、橘红色块 ✓、倾斜叠卡 ✓、「暖纸米白」（品牌级描述）✓                                                                                                                          |
|  V2  | 原尺寸裁剪，大字 OCR  |   ❌ 1/4    | displayLines 字符全对但全角标点被半角化（，→,）；**纹理印面上的强调句、反白 CTA、小字 eyebrow 三项全部编造**（真值：把软件生态留在纸页之外。/ 查看发布进度 / 本地优先的 Markdown 笔记工具） |
|  V3  | 原尺寸裁剪，细字 OCR  | ✅ 逐字全对 | © 2026 鸰湖科技（深圳）有限公司 ✓、LeankomStudio ✓、[支持,隐私,GitHub] ✓——0.75rem 50% 透明度细字也全对                                                                                      |
|  V4  | 双图比较              |   ✅ 全对   | sameContent ✓、移动端判定 ✓、5 条目 ✓                                                                                                                                                       |
|  V5  | 不存在文件 + 诚实出口 |   ✅ 诚实   | 如实 {"status":"unreadable","reason":"文件不存在…"}，零编造                                                                                                                                 |

**修正结论（替代 §3.5）**：M3 视觉读解**条件可用**，决定因素是背景干净度与任务粒度，而非图像本身：

- ✅ 可派：宏观布局/计数/有无判断（全页图可）；**干净纸底上的文字 OCR**（细至 0.75rem 低透明度也逐字正确）；双图比较；不存在文件能如实报告
- ❌ 禁派：**纹理/图案底上的文字**（印面强调句被编造）、**反白/低对比文字**（CTA 被编造）——失败模式仍是幻觉不报错
- ⚠️ 注意：全角标点可能被半角化（，→。→.），逐字类任务验收需对标点归一化或显式要求保留全角
- 工程前提（缺一不可）：产物绝对路径、输入为原尺寸裁剪图（主线程预制，见 `scratch/m3-probe/_harness/crop-v-assets.mjs`）、诚实出口条款、主线程真值对照
