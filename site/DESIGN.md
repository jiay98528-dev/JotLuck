## 1. 创意北极星（不变）

**羽翼印刷所 / The Winged Press**：一张刚从小型印刷机揭下的校样。暖纸、炭墨、装订深青、套准橙。装订、套准、批注与纸页层级说明一件事：纯文本可以轻盈，也可以精确。

继承的硬规则（详见原契约）：

- 装订四色纯 OKLCH：`--paper` / `--ink` / `--teal` / `--orange`（+书签黄/索引橄榄仅状态）；禁 hex、禁纯白纯黑、禁渐变、禁暗色面
- Hero 三要素同屏：巨型本地化主句 + 唯一主动作 + ≥40% 面积的真实编辑器证明；禁 50/50 正交分栏
- 编辑器证明 = 真实语义 DOM + 真实清洗 Markdown 管线（`@jotluck/renderer`），禁伪造截图
- 四层倾斜叠纸：`-4.2° / 2.6° / -1.6° / 0.8°`，露边 14/28/42px；确定性偏移，禁运行时随机
- 主句双字体：展示体语气段（炭墨）+ 正文粗体强调段（炭墨，橘红批准印面承托）；印面失败/打印/强制颜色一律回退炭墨
- 命名不对称圆角；Wing Sheet/Stack/Float 三级纸影；动效 80–400ms 禁 bounce/持续呼吸/布局属性动画；reduced-motion 全静态
- WCAG 2.1 AA；触控 ≥44px；焦点 2px 套准橙环；语义源码顺序优先于非对称视觉
