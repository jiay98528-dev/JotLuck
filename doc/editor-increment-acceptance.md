## 准备材料与共用操作

在临时验收笔记本中操作，不使用唯一的真实笔记副本。每条用例开始前恢复对应样本；修改后按 Ctrl+Z 验证一步撤销，再恢复样本开始下一条。即时编辑与分栏都需要输入，阅读模式只检查显示、定位、复制和打印准备。

### 材料 S：基础笔记

保存为 `基础.md`，另建 `目标.md`，内容为 `# 章节` 和一段正文。

````markdown
# 第一章

普通中文与 emoji 👩‍💻，**加粗**、_斜体_、~~删除~~、`代码`、[链接](https://example.com)。

- 普通项
- [x] 已完成

1. 第一项

> 引用
>
> - 引用里的项目

| 名称   | 数量 |
| ------ | ---: |
| 甲\|乙 |    2 |
| 丙     |    3 |

## 重复标题

首处 [[目标]]，同一行第二处 [[目标#章节|别名]]。

＃ 全角标题

－ 全角项目

# 下划线标题

## 重复标题

末处 [[目标]]。

```text
[[目标]] 只是一段代码
- 不应自动续为列表
```
````

### 材料 N：序号样本

每个样本单独粘贴到空笔记再操作，避免相邻样本相互影响。表中 `\n` 表示换行，`␠` 表示一个空格。

| 样本                                                            | 行尾 Enter 后新行开头           |
| --------------------------------------------------------------- | ------------------------------- |
| `1. 内容` / `1) 内容`                                           | `2.␠` / `2)␠`                   |
| `009、内容` / `（００９）内容`                                  | `010、` / `（０１０）`          |
| `(1) 内容` / `（1）内容`                                        | `(2)␠` / `（2）`                |
| `九、内容` / `（十九）内容` / `(九十九) 内容`                   | `十、` / `（二十）` / `(一百)␠` |
| `a. 甲\nb. 乙` / `A) 甲\nB) 乙`                                 | `c.␠` / `C)␠`                   |
| `i. 甲\nii. 乙` / `I) 甲\nII) 乙`                               | `iii.␠` / `III)␠`               |
| `①内容` / `⑲内容`                                               | `②` / `⑳`                       |

````powershell
$acceptanceDir = Join-Path (Get-Location) 'local-archive/editor-acceptance'
if (Test-Path -LiteralPath $acceptanceDir) { throw '请选一个新的空目录，保留上次验收材料。' }
New-Item -ItemType Directory -Path $acceptanceDir | Out-Null
$unit = '这是整本资料中的连续正文，用于检查输入与滚动。This is ordinary book prose with **emphasis** and a [reference][ref]. ' * 2
foreach ($size in @(1000000, 3000000)) {
    $book = [System.Text.StringBuilder]::new('# 大文档')
    $chapter = 0
    while ($book.Length -lt $size) {
        [void]$book.Append("`n`n## 第 $chapter 章`n`n")
        [void]$book.Append((@($unit) * 20) -join "`n`n")
        $chapter++
    }
    [void]$book.Append("`n`n[ref]: https://example.com`n`n末尾目标 [[目标]]`n`n> 九、尾部")
    Set-Content -LiteralPath (Join-Path $acceptanceDir "$size.md") -Value $book.ToString() -Encoding utf8NoBOM -NoNewline
}
$paragraph = '# 超长段落' + "`n`n" + ('长段落中英 text ' * 10000)
Set-Content -LiteralPath (Join-Path $acceptanceDir '超长段落.md') -Value $paragraph -Encoding utf8NoBOM -NoNewline
$code = '# 万行代码' + "`n`n" + '```ts' + "`n" + ((0..9999 | ForEach-Object { "const value$_ = $_;" }) -join "`n")
Set-Content -LiteralPath (Join-Path $acceptanceDir '未闭合围栏.md') -Value $code -Encoding utf8NoBOM -NoNewline
Set-Content -LiteralPath (Join-Path $acceptanceDir '万行代码.md') -Value ($code + "`n" + '```') -Encoding utf8NoBOM -NoNewline
$table = '# 万行表格' + "`n`n| Name | Value |`n| --- | ---: |`n" + ((0..9999 | ForEach-Object { "| row-$_ | $_ |" }) -join "`n")
Set-Content -LiteralPath (Join-Path $acceptanceDir '万行表格.md') -Value $table -Encoding utf8NoBOM -NoNewline
Set-Content -LiteralPath (Join-Path $acceptanceDir '目标.md') -Value '# 目标' -Encoding utf8NoBOM -NoNewline
Get-ChildItem -LiteralPath $acceptanceDir -File | Select-Object Name, Length
````
