## 修复的三个缺陷（都有修复前证据 + 修复后验证）

1. **DOCX 导出丢引用块文字**：引用导出后只剩空边框段，「> 引用」里的内容全部消失。
2. **DOCX 导出丢任务项与嵌套项**：`- [x] 已完成` 和缩进的子列表整块不进 DOCX。
3. **带别名的双链导出变乱码**：`[[目标#章节|别名]]` 导出 DOCX 后变成 `[别名](目标章节)` 这样的残缺字面文本；普通 Markdown 锚点链接同病。根因是「标签识别规则」把链接地址里的 `#锚点` 当成了 `#标签`。

提交 `8730fa3`；验收测试 41 号锁定新行为，Exporter 等价快照按新行为重拍。

## 需要你知道/定夺的事

1. **E1-02「只读打开」功能不存在**：应用内没有「以只读方式打开某条笔记」的入口（只读锁只在切换瞬间和外部文件会话生效）。「查找可用、替换禁用」的机制本身有实现。**要不要加这个功能入口是你的产品决策**；不加的话该用例永久不适用。
2. **WebKit 大纲高亮计时**：100ms 预算连续三次测得 113–119ms（功能正确，只是慢了十几毫秒），列为性能观察项，与 9-22 记录的 Firefox 跳转超标同类处理。
3. **两个小尾巴**：E4-03 的打印分页观感、E6-04 的真实文件重命名，自动路径覆盖不到，分别归入实机清单与后续 tauri 通道。
